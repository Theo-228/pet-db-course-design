## 当前项目定位

这是面向数据库课程设计的前后端分离应用，强调数据库建模、完整业务流程、持久化一致性以及可展示的数据库特性。项目应当以“宠物”为核心管理对象，而不是围绕家庭、猫咖等不同使用者分别拆两套系统。目前不考虑商业化。所有 AI 功能只保留可替换的调用接口/占位，不实施真实模型或算法。

**注意：**本仓库与既有的其他宠物硬件项目不应默认视为同一个代码库；未有明确需求前，不要把 ESP32、HarmonyOS、NearLink 等旧项目结构直接迁移到本课程设计。
